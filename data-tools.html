Export

CSV files open cleanly in LibreOffice Calc. The blank template has only the header row; keep those headings when filling it in.

Import

Gene Catalog

Add genes the starter catalog does not have. Download the blank sheet, fill in one gene per row, then import it. Existing starter and custom genes are never replaced. Columns: name, type (codom or recessive), superType (viable, lethal or none), allelicGroup, health and superName. Only name is required.

Gene Shortcuts

Import the abbreviations you use, one per row. If a row names one of your own genes, import the gene sheet first. Existing shortcuts are kept; importing the same shortcut again updates which gene it points to. Columns: alias, gene. Example: YB, Yellow Belly.
